# 随机小姐姐视频插件

一个为 AstrBot 开发的随机小姐姐视频插件，可以获取随机的小姐姐视频内容。

## 功能特性

- 🎬 获取随机小姐姐视频
- 🚀 支持多种触发指令
- ⚡ 异步处理，响应迅速
- 🔧 可配置API参数
- 📝 完整的日志记录

## 安装方法

1. 将插件文件夹放置到 AstrBot 的插件目录中
2. 重启 AstrBot 或重新加载插件
3. 插件将自动加载并可使用

## 使用方法

### 基础指令

- `/小姐姐` - 获取随机小姐姐视频
- `/随机小姐姐` - 获取随机小姐姐视频
- `/看小姐姐` - 获取随机小姐姐视频
- `/美女视频` - 获取随机小姐姐视频
- `/看美女` - 获取随机小姐姐视频

### 使用示例

```
用户: /小姐姐
机器人: [发送随机小姐姐视频]

用户: /随机小姐姐
机器人: [发送随机小姐姐视频]
```

## 配置说明

插件支持以下配置项（在 `_conf_schema.json` 中定义）：

### API配置

- **api_url**: 小姐姐视频API接口地址
  - 类型: `string`
  - 默认值: `https://api.nycnm.cn/api/v2/video`
  - 说明: 设置获取随机小姐姐视频的API接口地址

- **api_key**: API密钥（如果需要）
  - 类型: `string`
  - 默认值: `""`
  - 说明: 某些API可能需要密钥验证
  
- **timeout**: API请求超时时间（秒）
  - 类型: `int`
  - 默认值: `15`
  - 说明: 设置API请求的超时时间，建议10-30秒

## 技术实现

### 核心功能

1. **异步HTTP请求**: 使用 `aiohttp` 进行异步HTTP请求
2. **视频组件**: 使用 AstrBot 的 `Video.fromURL` 组件发送视频
3. **错误处理**: 完善的异常处理和日志记录
4. **会话管理**: 使用持久化的HTTP会话提高性能

## 注意事项

1. **网络环境**: 确保网络连接正常，API可访问
2. **API限制**: 注意API的调用频率限制
3. **内容合规**: 视频内容随机，请注意使用环境
4. **错误处理**: 如遇获取失败，插件会自动重试或提示错误

## 错误排查

### 常见问题

1. **视频获取失败**
   - 检查网络连接
   - 验证API地址是否正确
   - 确认API密钥是否有效

2. **插件加载失败**
   - 检查依赖包是否安装
   - 确认插件文件完整性
   - 查看AstrBot日志

3. **超时问题**
   - 调整timeout配置
   - 检查网络延迟
   - 更换API接口

### 日志查看

插件会记录详细的运行日志，包括：
- 用户请求记录
- API调用状态
- 错误信息详情
